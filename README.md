# PointBlankJelly Fabric 1.21.1 - Fix For Mobile

Mobile compatibility fix for Point Blank 2.2.0 on Minecraft 1.21.1 Fabric.

## Features

- Includes the required Groovy 4.0.13 runtime
- Fixes Groovy script compatibility with Fabric's intermediary mappings
- Fixes runtime errors in Point Blank's Groovy scripts

## Version

- Minecraft: 1.21.1
- Point Blank: 2.2.0
- Fabric Loader: 0.19.5
- Groovy: 4.0.13

## Installation

1. Download the latest `.jar` from **Releases**.
2. Replace the original Point Blank `.jar` in your `mods` folder.
3. Launch Minecraft with Fabric 1.21.1.

The Groovy runtime is already included. You do **not** need to install `groovy-4.0.13.jar` separately.
